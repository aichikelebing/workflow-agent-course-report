\phantomsection\section*{摘要}
\addcontentsline{toc}{section}{摘要}

工作流和智能体都能在一条线索缺失后改查另一条线索。本文将二者的边界落在论文去重时的一项决策上：给定相同的题名、可选字段和查询预算，谁来决定下一步查什么？在 DBLP–ACM 基准的 32 对测试记录上，我们比较了固定顺序、条件分支和由模型逐步选择字段三种策略。其匹配 F1 分别为 0.865、0.811、0.833，共查询字段 64、23、11 次。模型比条件分支多判对的一例来自同一期刊缩写未对齐；固定全部选字段动作、补上这条别名后，两者对 32 个样本的预测完全一致。对另外构造的配对条件进行穷举重放，16 个决策状态中有 5 个会因第二步动作不同而改变分类。这个结果说明，核验智能体的贡献需要同时查看动作由谁选择、动作是否改变答案，以及改变答案的证据是否可靠。\par

\textbf{关键词}　实体匹配；主动特征获取；工作流；工具调用；反事实重放\par

\section{研究背景与问题}

两条书目记录题名相近，一条把作者写成全名，另一条只保留了姓氏和首字母。合并它们可能消除一条重复记录，也可能把两篇独立论文误并。假设核验者只能再看一个字段，查年份、查发表会议和直接结束分别会带来什么结果？这个具体选择把数据挖掘中的实体匹配问题和智能体的执行机制联系了起来。\par

我们研究的是候选记录对的核验环节。系统起初看到两个题名，随后可以请求作者、年份或发表渠道。一次查询同时返回两侧同一个字段。两次查询的上限是实验设置，用来观察不同策略在证据不足时如何取舍；在已经持有完整书目表的常规离线去重中，读取同一行的额外一列几乎没有成本。\par

本文回答两个问题。第一，当规则和模型都能根据新信息改变路线时，可以从哪里辨认下一步的决定者？第二，在相同数据、相同判定器和相同查询上限下，把字段选择权交给模型，能否改变误合并、漏合并以及取证开销？\par

\section{已有方法与研究切入点}

\subsection{工作流的分支与智能体的局部控制权}

Anthropic 在工程实践中区分由预设代码组织的工作流，以及由模型在运行时根据环境反馈组织工具调用的智能体；路由和反复评价都可以出现在工作流中 [1]。例如，系统返回“作者为空”后，程序的一行条件判断可以指定查年份，模型读取反馈后也可以选中年份。两条执行记录的字段顺序完全一样。要判断它们采用了哪一种机制，还要看调用发生前，是规则已经指定了动作，还是模型在仍然可用的动作中作出了选择。\par

本实验以一次选字段决策为观察单位。动作集合、查询上限和最终判定方式始终由程序约束。我们把能够反复观察工具反馈、选择下一个字段并主动停止的模型称为“有限自主 Agent”。这个定义只覆盖书目取证环节，也允许一个较大的工作流在某个节点内部采用模型控制。\par

\subsection{实体匹配与按需获取字段}

同一篇论文在不同系统里可能使用不同引号、简称、作者拼写和会议缩写。Köpcke 等比较过多种实体匹配方法的效果与效率 [2]。Wang 等进一步研究了大模型在匹配、比较和选择候选记录等任务中的表现 [3]。另一个相关问题是主动特征获取，即在测试时决定要看哪个特征、何时收集足够的信息停止 [4]。这里将二者结合：每对书目的真实对应关系用来评分；控制器只负责挑选交给判定器的字段。这使“选对了证据”和“擅长给出最终答案”可以分开考察。\par

\section{实验方法与原创设计}

\subsection{样本与公平比较的条件}

采用莱比锡大学数据库研究组发布的 DBLP–ACM 基准 [5]。按本次使用的 CSV 实际读取结果，两个来源分别有 2,616 和 2,294 条书目，真值文件含 2,224 对匹配。正例从真值映射取出。对每条 DBLP 记录，从含有共同题名词的 ACM 候选中，排除真值对应项，再选题名最相近的一条作为非匹配候选。这让“看起来很像但不该合并”的论文有机会进入测试。\par

先按真值关系把同一实体的记录放在同一分区，再以固定种子抽取 8 对开发样本和 32 对测试样本。开发集用于核验程序流程。测试集匹配和非匹配各 16 对，每类各半来自困难层：正例中题名较不相似、负例中题名较相似的前 20\% 构成各自的困难层。这个配比服务于策略对照；实际数据库中的重复率需要另行估计。\par

\subsection{三种取证策略与共同判定器}

\bottomrule
\end{longtable}\endgroup
三个系统使用同一确定性判定器。首先把题名规范化为词集合，用交集词数的两倍除以两边词数之和得到 Dice 相似度，基础分为这个相似度减 0.78。查到作者后，加上 0.32 \ensuremath{\times}（2 \ensuremath{\times} 作者姓氏集合的 Dice 相似度 \ensuremath{-} 1）；年份相同加 0.12，不同减 0.22；来源经别名归一后相同加 0.10，不同减 0.15。任一侧缺值时，该字段贡献为零。总分达到零就判为同一篇。固定同一个判定器，使每一个选字段决策都能在相同判定条件下重放。\par

B 直接读取分数和阈值。C 只得到定性指令、两个题名、已经查询的字段和剩余动作，不接触匹配标签及判定分数。主实验在 Codex 对话环境中分两批推理：第一批返回各记录的首步动作，第二批只返回请求过字段的记录及其反馈。实际输入和动作均已留档。一次选字段、一次模型决策和一次批量推理分别计数，因而既能比较取证量，也能看到调度模型本身的额外开销。\par

\subsection{原创验证：只改作者反馈，再重放所有第二步}

第一步，选出作者两侧完整、题名基础分最接近零的 8 对测试记录。对每对构造两个版本，一版保留两侧作者，另一版只把 ACM 侧作者置空。固定第一步查作者，其余可见信息、真实标签和剩余的一次预算保持一致。两个条件用独立模型上下文和不同顺序的编号，以免控制器通过另一版直接看见被遮盖的内容。\par

第二步，记录三种策略实际上选择的动作。然后让共同判定器把同一状态的三个合法后续分别算一遍：直接停止、查年份、查发表来源。若三条路径给出同一分类，路径差异在该状态下没有影响分类；若分类发生分歧，再用真值核验哪项操作挽回了错误、哪项操作引入了错误。8 对 \ensuremath{\times} 2 个版本 \ensuremath{\times} 3 种后续，共得到 48 条可核查路径，来自 8 对基础记录。\par

第三步，对决定组间差异的记录回查原始字段。系统可能恰好预测正确，却依赖了错误的同义词归一或不恰当的字段权重。把这一步与反事实重放连用，可以继续追问：如果正确处理那条证据，原来的策略优势还存在吗？\par

\subsection{胜出的那一例：期刊缩写改变了答案}

B 和 C 有 31 对给出相同答案，唯一的分歧是 T28。两条题名分别为“Charter and Scope”和“Editorial: Charter and scope”，作者均为 Won Kim，年份分别为 1994、1995。基准将其标为不同论文。B 查看作者后误合并；C 只查了发表来源，恰好判对。\par

这两条来源分别写作“ACM Trans. Database Syst.”和“ACM Transactions on Database Systems (TODS)”，实际指同一本期刊。原判定器把缩写和全称当成不同来源，给 C 扣了 0.15 分。我们在看过此例后补作定向检查：固定三组全部 96 条查询路径和其余规则，只把这两个写法对齐，来源项由减 0.15 变为加 0.10。只有 C 在 T28 上的预测翻转，其 F1 从 0.833 降到 0.811，与 B 对所有测试对的判断逐条一致。这个事后检查保留了原始主表，也解释了为什么一项表面优势经不起字段核验。\par

\section{研究结论与创新点}

\textbf{关于界限。} 在限定的字段采集任务内，区分机制需要检查“下一动作由谁生成”。B 可以根据作者反馈改变分支，C 也可能反复选中相同分支。即使两种系统对全部测试记录作出相同分类，代码中由规则指定动作和由模型根据反馈选择动作仍是两种可核查的实现方式。\par

\textbf{关于价值。} 在这次 32 对测试中，固定顺序有最高 F1，模型控制器用了最少的字段查询。模型相对条件分支原本多判对的一例，可追溯到判定器漏识同刊缩写。因而本实验能支持“模型在此配置下少查了 12 次字段”，尚无证据支持“模型取得了更可靠的匹配质量”。\par

\textbf{本报告的原创贡献。} 我们把同一状态下三种第二步动作逐一重放，分清了“动作不同但答案不变”“不同动作都能纠错”和“只有特定动作可以纠错”。在此基础上，我们又固定历史动作，单独修正一个能被原始字符串证实的别名问题。两次核验分别检验选字段的效果和判定器如何使用证据，让一次得分差异可以追溯到具体记录、具体操作。\par

\textbf{适用范围与下一步。} 这次仅使用书目数据、一个固定判定器、一次有意分层的小样本测试。B 知道精确分数，C 只收到定性目标；同批样本共享模型上下文。重放已记录的动作可以复现分数，重新询问模型可能得到其他选择。下一轮可在独立样本上比较“两个控制器都看到分数”和“都只看到原始字段”两种设定，同时用同作者、同主题但不同篇的记录检验作者加分；阈值和别名表应在新一轮测试前冻结。\par
